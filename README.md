# 📊 TechPulse Analytics

## Mobile & Laptop Sales Intelligence Dashboard

TechPulse Analytics is an interactive **Data Analytics and Machine Learning dashboard** built using Python and Streamlit.

The project analyzes historical **mobile and laptop sales data** to generate useful business insights related to revenue, products, brands, regions, sales trends, pricing, and dispatch operations.

It also includes a **Machine Learning Price Predictor** that learns from historical sales data and estimates the price of a new product profile.

---

## 🚀 Project Overview

The main goal of this project is to convert raw sales data into meaningful and easy-to-understand business insights using:

- Data Cleaning
- Data Preprocessing
- Exploratory Data Analysis
- Data Visualization
- Sales Analysis
- Product Analysis
- Brand Analysis
- Regional Analysis
- Operations Analysis
- Machine Learning
- Interactive Dashboard
- CSV Data Export

The dashboard allows users to upload their own CSV dataset or use the default dataset provided with the project.

---

## 🎯 Objectives

The main objectives of TechPulse Analytics are:

1. Analyze mobile and laptop sales data.
2. Calculate total revenue and units sold.
3. Identify high-performing products.
4. Compare different brands.
5. Analyze regional sales performance.
6. Understand price and quantity relationships.
7. Analyze dispatch lead time.
8. Identify data-quality issues.
9. Train a Machine Learning model using historical data.
10. Predict the estimated price of a product.
11. Provide an interactive and professional analytics dashboard.
